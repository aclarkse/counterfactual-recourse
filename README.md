# Mediation-aware causal recourse

This repository contains the code to reproduce the results in the paper
*When Do Interventions Close the Gap? Mediation-Aware Algorithmic Recourse*.

## Motivation

Algorithmic recourse tells a person who was denied a favorable decision what
to change to get a different outcome. When a sensitive attribute $X$ affects
the decision partly *through* actionable mediators $W$ (education, occupation,
hours worked, test scores), ordinary recourse only asks whether a recipient
crosses the classifier's threshold. It can stop short of the disparity carried
by those mediators, or push recipients well past it.

This repository implements recourse that targets that mediated disparity
directly. For a disadvantaged recipient with pre-treatment covariates $z$, the
target is the distribution of scores the recipient would receive under the
advantaged group's mediator law $P(W \mid X=x^{(1)}, z)$. Among actions that
make the recipient valid with probability at least $\gamma$, the method returns
the cheapest one whose interventional score distribution lies within
$\varepsilon$ of that target in 1-D Wasserstein distance. When no such action
exists, it abstains, and it reports why: no valid action, a target that no
valid action can match, or a target the action grid cannot reach.

The mediator distribution is learned with a block-ordered model: categorical mediators
get autoregressive neural heads, and the continuous mediators share one
conditional neural spline flow. Interventions clamp the acted-on mediators
and redraw their descendants. All effects are measured on a fixed classifier's
prediction scale.

## Setup

Requires Python 3.11+ and [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

`pyproject.toml` pins a CUDA 12.8 PyTorch build. For CPU or another CUDA
version, point `[tool.uv.sources]` at a different `pytorch-*` index, then run
`uv lock && uv sync`.

**Data.** ACS Income (via `folktables`) and UCI Adult download automatically
on first use. German-Synth is generated by `data/german_synth.py`. Law School
must be converted to `data/bar.csv` as described in
`data/BAR_DATA_PROVENANCE.md`.

## Running

The full pipeline for each dataset and seed is: fit the mediator model, fit
the classifiers, estimate effects, then run recourse. Run it with:

```bash
uv run python -m evaluation.run_multiseed \
  --datasets german_synth german_synth_m0 german_synth_m05 german_synth_m2 \
             bar acs adult \
  --seeds 42 43 44 45 46 --resume
```

Results are written to `outputs/multiseed/`, with per-seed artifacts and
`summary.{json,csv,md}`. To run single stages for one dataset (the configs are
in `conf/dataset/`):

```bash
uv run python -m flows.train_flow dataset=acs        # mediator model
uv run python -m outcome.train_outcome dataset=acs   # classifiers
uv run python -m evaluation.estimate_gap dataset=acs # NDE / NIE / TE
uv run python -m evaluation.ablate_recourse dataset=acs
```

To build the figures and tables from `outputs/multiseed/`, and to run the
tests:

```bash
uv run python diagnostics/plot_main_figures.py
uv run python diagnostics/make_appendix_tables.py
uv run python -m unittest discover -s tests
```

## Layout

```text
conf/dataset/   dataset roles, mediator blocks, model and recourse settings
data/           loaders and data provenance notes
flows/          block-ordered mediator model and interventional sampling
outcome/        fixed classifiers (logistic regression, MLP, random forest)
evaluation/     effect estimation, recourse, multi-seed runner
diagnostics/    figures and tables
tests/          unit tests
```
