# Generated outputs

The checked-in `gaps/`, `recourse/sweep_lambda_*`, and associated figures were
generated by the pre-revision pipeline. In particular, the old recourse tables
label a pointwise direct prediction gap as `NIE_post` and vary the shortfall
weight while calling the result a lambda sweep. They are retained only as
legacy artifacts and must not be used in the revised submission.

Regenerate results after retraining the block-ordered mediator model. Corrected
recourse ablations are named `ablation_<dataset>_<model>.{json,csv,tex}` and
include explicit population, objective, reference, seed, and interval metadata.
They use direct-action interventions with strict-descendant propagation and
label the stochastic-plan transport term as a conservative coupling upper
bound, not exact joint Wasserstein distance.
